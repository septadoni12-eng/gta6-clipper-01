An entry for make.fun's "Clip GTA 6 for the most YouTube views" bounty: a short vertical clip of Windah Basudara reacting as Jason squats 150 kg in GTA VI, cut fresh from his livestream, with make.fun's pitch burned in at the end — "Make clips like this with AI and earn money on make.fun". The clip is public on YouTube as a Short, and this repository hands in its address in VIDEO.json; main.ts copies VIDEO.json to the output directory, which is all the program has to do. Places go by the video's views at the deadline; the top 20 share $500 in USDC.

## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```
